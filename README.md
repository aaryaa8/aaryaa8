### Axial

An AI platform that maps how each student thinks and converts those patterns into task-specific study strategies. I lead product, design, and engineering across the whole stack: the explainable cognitive model, the interactive knowledge graph, and a voice coach that talks a student through their own reasoning.

Built with Next.js, TypeScript, Supabase, and Claude. The voice layer connects Axial's cognitive model to a real-time coach through the Model Context Protocol and ElevenLabs.
